# Racimo

🍇 [Live demo](https://pgreyesm.github.io/racimo/) · [Read the manifesto](manifesto.md)

A UX proposal for conversations with Claude. Three integrated ideas:

1. **Spatial navigation** — chats as grapes grouped into clusters by topic, not as a vertical scroll.
2. **Branching with context inheritance** — any response can fork into a sub-branch that inherits the parent's full context. Git for thinking.
3. **Distillation as a first-class output** — whole clusters synthesized into downloadable, persistent text.

The prototype is a single self-contained HTML file with no dependencies. The manifesto is ~600 words. Both are bilingual (English / Spanish).

## In this repo

- [`index.html`](index.html) — Navigable prototype, runs in any browser. State persists in localStorage.
- [`manifesto.md`](manifesto.md) — Manifesto in English.
- [`manifiesto.md`](manifiesto.md) — Manifesto in Spanish.
